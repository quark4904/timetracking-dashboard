## 검증 계획

- 임시 DB에서 저장소 및 개발 서버 HTTP 테스트 실행.
- 배포용 FastAPI 테스트 실행; 테스트용 의존성은 운영 requirements와 분리.
- 원본 마이크로초 보존, 시간 변경, 월말·윤년·자정 기본값 계산 회귀 테스트.
- 응답 순서를 제어하여 캐시 복귀 및 전체 갱신 경합 검증.
- 정적 파일 버전의 전파와 반복 실행 시 무변경 확인.
- 브라우저에서 실제 저장 payload와 모바일 입력·탭 조작 확인.

## 검증 결과

- Python 3.13 임시 가상환경: `python -m unittest discover -v` **25개 통과**, skip 없음. 저장소·개발 서버 HTTP·FastAPI·정적 계약·캐시 버전 전파 검사 포함.
- `node tests/test_frontend_math.mjs` 통과. 변경하지 않은 마이크로초 보존, 시간/날짜 변경, 잘못된 날짜, 월말 양방향·연말·윤년 이동, 자정 직후 기본값 확인.
- `node --input-type=module --check < app/static/app.js`, Python 문법 검사 및 `git diff --check` 통과.
- Chromium 브라우저 회귀 테스트 **6개 통과**: 메모 편집 후 짧은 세션의 정확한 시각 보존, 월말 이동, 오늘 기본값 저장, 캐시된 달 복귀 후 지연 응답 무시, 삭제 후 오래된 전체 갱신 무시, 모바일 편집·Tab 순서·활성 세션 Stop.
- API/브라우저 실행은 임시 DB와 localhost 서버를 사용했다. 테스트 의존성과 브라우저는 `/tmp`에 격리하여 준비했다.
- `docker build --tag timetracking-dashboard:review-20260908 .` 통과. Python 3.12 이미지 빌드 중 정적 파일 버전 스크립트 실행도 확인했다. 컨테이너 실행·배포는 하지 않았다.

## 검증 한계 및 후속 확인

- 모바일 테스트는 Chromium의 iPhone 13 뷰포트·터치 에뮬레이션이다. WebKit은 시스템 라이브러리가 없어 실행하지 못했으며 실제 iOS Safari의 키보드·safe-area·다이얼로그 스크롤은 기기 확인이 필요하다.
- 브라우저 테스트는 개발 서버를 사용한다. 배포용 FastAPI는 별도 TestClient 테스트로 검증했다.
- 여러 기기에서 같은 세션을 동시에 편집할 때의 충돌 검출은 이번 변경에 포함하지 않았다.

테스트 설치·실행 방법은 [README](../README.md#테스트)를 따른다.
