# Timetracking Dashboard TODO

## 전제

- 외부 접근 인증은 Cloudflare Access가 담당한다. 애플리케이션 자체 로그인/PIN은 범위에서 제외한다.
- 저장 시각은 UTC, 표시 시각은 `Asia/Seoul`을 사용한다.
- 기능을 수정할 때 기존 저장소 테스트와 핵심 사용자 흐름 테스트를 함께 갱신한다.

## P0 — 데이터 무결성과 오류 처리

- [x] 미래 완료 세션 저장 차단
  - `ended_at`이 현재 시각보다 미래인 경우 API가 400을 반환하도록 한다.
  - 시작 시각도 종료 시각보다 미래일 수 없도록 함께 검증한다.
  - 미래 세션과 잘못된 시간대에 대한 저장소/API 테스트를 추가했다.

- [x] 세션 시간 입력 일관성 검증
  - 종료 날짜와 종료 시간 중 하나만 입력된 경우 저장을 차단한다.
  - 시·분을 별도 입력으로 나누고 `시작 시 → 시작 분 → 종료 시 → 종료 분 → 시작 날짜 → 종료 날짜` 탭 순서를 보장한다.
  - 시작·종료 시간이 비어 있거나 잘못된 형식일 때 인라인 오류를 표시한다.
  - 클라이언트·서버 오류를 영어 UI 메시지로 매핑한다.

- [x] API 오류 상태를 UI에 표시
  - 네트워크 오류, 400/409 응답, 저장 실패를 공통 Toast 또는 인라인 메시지로 표시한다.
  - 저장·삭제·세션 시작/중지 중에는 중복 요청을 막는다.
  - 자동 새로고침 오류도 Toast로 표시하며, 최신 요청 세대만 화면에 반영한다.

- [x] 활성 세션 동시성 검증 강화
  - 세션 중지와 작업 시작 요청이 동시에 발생해도 활성 세션이 하나만 남는지 테스트한다.
  - SQLite `BEGIN IMMEDIATE`와 unique partial index를 사용하고, 상태 변경 후 전체 표시 데이터를 다시 동기화한다.

## P1 — 핵심 기능 개선

- [x] Archive 작업 복구 지원
  - Archive 목록에서 `Unarchive` 버튼을 제공한다.
  - 복구 후 All Tasks 목록과 순서를 즉시 갱신한다.

- [x] 수동 세션 겹침 정책 결정 및 적용
  - 겹치는 완료 세션은 허용하지 않고 저장 시 409로 거부한다.
  - 자정 넘김 세션과 활성 세션을 포함한 겹침 테스트를 추가한다.

- [x] 모바일에서도 활성 세션 제어 유지
  - Tasks 외 Timeline, Reports, Settings에서도 활성 세션과 Stop 동작을 확인할 수 있게 한다.
  - 하단 네비게이션 및 홈 인디케이터와 겹치지 않도록 safe-area를 적용한다.

- [x] 기간·날짜 요청 경쟁 상태 방지
  - 날짜 이동 또는 리포트 기간을 빠르게 변경할 때 이전 응답이 최신 선택값을 덮어쓰지 않도록 한다.
  - `AbortController` 또는 요청 세대 번호를 사용하고, 최신 요청만 상태에 반영한다.

- [x] 작업 순서 변경의 키보드·터치 대안 제공
  - Drag & Drop 외에 위로 이동/아래로 이동 버튼 또는 키보드 조작을 제공한다.
  - 모바일에서 작업 순서 변경이 가능한지 확인한다.

## P1 — 접근성과 UI 일관성

- [x] 필터 탭 접근성 보완
  - `role="tab"`, `aria-selected`, `aria-controls`를 올바르게 적용한다.
  - 키보드 방향키로 탭을 이동하고 선택할 수 있게 한다.

- [x] 리포트 기간 선택 의미 개선
  - `strong role="button"` 대신 실제 `button`을 사용한다.
  - 현재 기간, 이전 기간, 다음 기간의 접근성 라벨과 포커스 상태를 명확히 한다.

- [x] 커스텀 Task 선택 메뉴 접근성 보완
  - `aria-controls`, `aria-activedescendant`, 키보드 방향키, Enter, Escape를 지원한다.
  - 메뉴가 닫힐 때 원래 버튼으로 포커스를 복귀한다.

- [x] 다국어·시간 표시 정책 정리
  - 기존 화면 언어인 영어로 UI 오류 메시지와 시간 표시를 통일한다.
  - 날짜·요일·오전/오후·에러 메시지의 표시 언어를 일관되게 한다.

- [x] 포인터 전용 Tooltip 보완
  - 차트 정보가 마우스 hover에만 의존하지 않도록 키보드 포커스와 모바일 탭에서도 확인할 수 있게 한다.

## P2 — 운영과 성능

- [x] Settings의 Docker 포트 설명 수정
  - 현재 실제 컨테이너 포트는 8000인데 화면에는 8080으로 표시된다.
  - [app/static/index.html](app/static/index.html)의 안내 문구를 `8000`으로 수정한다.

- [x] 세션 조회 인덱스 추가
  - `sessions(started_at, ended_at)` 조회 패턴을 기준으로 인덱스를 검토한다.
  - 조회 인덱스를 추가했다. 운영 데이터 규모별 월·주·연 리포트 시간 측정은 배포 후 관찰 항목이다.

- [x] API와 개발 서버 동작 통합
  - `app/main.py`와 `dev_server.py`의 라우팅·검증·오류 응답 차이를 줄인다.
  - 비즈니스 검증은 repository에 두고, 개발 서버도 FastAPI와 같은 JSON 오류 형식과 상태 코드를 사용한다.

- [x] 프론트엔드 모듈 분리

  - 모듈별 계산 테스트를 추가해 화면 이벤트 코드와 계산 코드를 분리했다.

- [x] 정적 파일 캐시 버전 관리 자동화
  - 수동 쿼리스트링 버전 변경을 빌드 또는 배포 단계에서 자동화한다.
